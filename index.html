20 etiquetas de HTML

1 <h1> Titulo principal

Para que sirve: senala el titulo mas importante de la pagina. 

<h1>Titulo principal</h1>

Titulo principal

2 <h2> Subtitulo

Para que sirve: divide el contenido en secciones. 

<h2>Subtitulo de seccion</h2>

Subtitulo de seccion

3 <p> Parrafo

Para que sirve: organiza un bloque de texto en forma de parrafo. 

<p>Este es un parrafo.</p>

Este es un parrafo de ejemplo.

4 <strong> Texto importante

Para que sirve: indica que una palabra o frase tiene importancia. 

<strong>Texto importante</strong>
Texto importante

5 <em> Enfasis

Para que sirve: resalta una palabra y normalmente aparece en cursiva. 

<em>Texto con enfasis</em>
Texto con enfasis

6 <mark> Texto resaltado

Para que sirve: destaca informacion como si tuviera un marcador. 

<mark>Dato importante</mark>
Dato importante

7 <a> Enlace

Para que sirve: permite ir a otra pagina o seccion. 

<a href="https://www.google.com">Ir a Google</a>
Ir a Google

8 <div> Contenedor

Para que sirve: agrupa elementos para ordenarlos o aplicarles estilos. 

<div>Contenido agrupado</div>
Contenido agrupado

9 <span> Fragmento de texto

Para que sirve: selecciona palabras para aplicarles un estilo. 

<p>Texto <span>especial</span>.</p>

Este texto tiene una palabra especial.

10 <br> Salto de linea

Para que sirve: hace que el contenido continue en la siguiente linea. 

Primera linea<br>Segunda linea
Primera linea
Segunda linea

Para que sirve: representa un cambio de tema con una linea horizontal. 

<hr>

<ol>

  2. Crear index.html

Para que sirve: explica que informacion debe escribirse.

Para que sirve: permite escribir o seleccionar informacion. 

<input type="text" placeholder="Escribe tu nombre">

Para que sirve: crea un boton que puede ejecutar una accion.

20 propiedades de CSS

Sintaxis general de CSS

selector {
    propiedad: valor;
}

El selector indica que elemento se modificara, la propiedad indica que aspecto cambiara y el valor define el resultado.

1color

Cambia el color del texto.

color: #156b4a;
Texto verde

2background-color

Cambia el color del fondo.

background-color: #dff3e8;
Fondo de color

3font-size

Define el tamano de la letra.

font-size: 24px;
Texto grande

4font-family

Selecciona el tipo de letra.

font-family: Georgia, serif;
Otra tipografia

5font-weight

Controla el grosor de las letras.

font-weight: bold;
Texto grueso

6text-align

Alinea el texto horizontalmente.

text-align: center;
Texto centrado

7line-height

Modifica el espacio entre lineas.

line-height: 2;
Linea numero uno.
Linea numero dos.

8margin

Crea espacio por fuera del elemento.

margin: 20px;
Margen exterior

9padding

Crea espacio entre el contenido y el borde.

padding: 20px;
Espacio interior

10border

Agrega un borde al elemento.

border: 2px solid #156b4a;
Elemento con borde

11border-radius

Redondea las esquinas.

border-radius: 18px;
Esquinas redondas

12width

Define el ancho de un elemento.

width: 60%;
60% de ancho

13height

Define la altura de un elemento.

height: 80px;
80px de alto

14display

Determina como se acomoda un elemento.

display: flex;
A B C

15gap

Agrega separacion entre elementos.

gap: 18px;
1 2 3

16box-shadow

Agrega una sombra alrededor.

box-shadow: 0 5px 14px #aaa;
Elemento con sombra

17opacity

Controla la transparencia.

opacity: 0.5;
50% de opacidad

18text-transform

Cambia el uso de mayusculas y minusculas.

text-transform: uppercase;
Texto en mayusculas

19letter-spacing

Modifica el espacio entre letras.

letter-spacing: 5px;
ESPACIO

20cursor

Cambia la apariencia del puntero.

cursor: pointer;
Coloca el cursor aqui
